# Public Assets

Place your logo and other static assets in this directory.

## Logo

Your baby elephant logo is already configured! 

**To add your logo:**

1. Save your baby elephant logo image as `logo.png` in this `public/` folder
2. The logo will automatically appear in the navigation
3. The logo is displayed in a light pink circle background to match your design

**Supported formats:**
- PNG (recommended for transparency)
- SVG (scalable, best quality)
- JPG (if you don't need transparency)

**Current setup:**
- Logo displays in a 48x48px pink circle
- Automatically scales and centers
- Shows on all pages in the navigation

## Images

You can also add product images, hero images, and other assets to this directory.
Access them in your code using `/filename.ext` (e.g., `/product-image.jpg`)
